# Agency operating notes (file stand-in for HQ)

JeremAI is an **ops CLI**, not a SaaS creative studio.

Pipeline we sell:

1. Human brief / winning ad (10–15%)
2. Agent: script, B-roll search/reuse, generate, assemble (~90%)
3. Human editor polish (~10%)
4. Human publish — never the agent

Wedge vs Creatify / Arcads / AdCreative.ai / Pencil: those are web UIs optimized for avatar volume. This tool sits in the agency’s Drive/R2, enforces Nutra claims, meters $/client, and hands Premiere-ready cuts to editors who already live in chat + Ads Manager.
